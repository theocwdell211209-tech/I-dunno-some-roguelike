# I-dunno-some-roguelike

A mobile-friendly Yu-Gi-Oh 2D deck builder roguelike (card pool capped at Arc-V era).

## Run

Open `/home/runner/work/I-dunno-some-roguelike/I-dunno-some-roguelike/index.html` in a browser.

## Features

- Touch-friendly UI with responsive layout
- Arc-V-and-earlier card pool for deck building
- 2D grid roguelike map rendered on canvas
- Turn-based battles powered by cards from your built deck
